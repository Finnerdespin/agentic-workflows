# Update architecture documentation

Use this skill to update the documentation of the architecture of this application. 
Whenever explicitly asked, or if changes to the code are meaningful enough to be considered as architecture changes, keep the documentation up-to-date.

The location of the documentation is documentation/architecture.md.

The goal of that documentation is to serve an always up-to-date reference for developers/humans, and for LLM agents as well, when developing new features, or reviewing the code.

## Constraints

- Keep the documentation more high-level than deeply describing the code.
- Keeping the references to files/functions is acceptable.
- Concentrate on the "why" question more, rather than on "how" and "what" (although it is also important).
